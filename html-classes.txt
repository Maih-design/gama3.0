==================================================
PROJECT HTML CLASS NAMING REFERENCE
==================================================

General rule:
- Use classes for styling and repeated elements.
- Use IDs only for unique elements or JavaScript targets.
- Use BEM-like naming where useful.
- Keep names in English.
- Do not create a new class if an existing general class can be reused.
- Page-specific classes are allowed when the component is genuinely unique.

==================================================
IMPORTANT
==================================================

Do NOT automatically use every class.

Use the most general existing class whenever possible.

Example:

Good:
<button class="btn btn-primary">

Bad:
<button class="patient-add-green-large-button">

For a reusable table:
<table class="data-table">

For a patient-specific component:
<div class="patient-card">

For a unique print document:
<div class="referral-document">

IDs should be used only when:
1. JavaScript needs the element.
2. A form needs a unique identifier.
3. An element is genuinely unique on the page.

Avoid using IDs just for CSS.
